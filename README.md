# Flexsmith

Trzecia aplikacja rodziny Smith (obok Runsmith i Repsmith): mobilność, rozciąganie, przygotowanie do ruchu i opcjonalne rolowanie, offline, bez kont. Hasło: **Move better. Every day.**

Status: audyt i prototyp do akceptacji. Zobacz `docs/AUDIT.md` i `docs/PROTOTYPE.md`.

- `prototype/`: interaktywny prototyp wizualny
- `design/master/`: dostarczone mastery ikony (kafel `#8071B4`, znak biały)
- `smith-design-system-v1/`: Smith Design System v1 (kopia z Runsmith i Repsmith)
- `docs/`: audyt, architektura, ryzyka
